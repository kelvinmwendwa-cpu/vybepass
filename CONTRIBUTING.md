# Contributing

Contributions are welcome. Kelvin Mwendwa maintains this project and reviews proposed changes before merging them.

## Start here

- Open an issue describing a bug or feature before starting a large change.
- Include steps to reproduce, expected and actual behaviour, and your device or environment. Remove personal data from screenshots and logs.
- Fork this repository, create a branch, make a focused change, and open a pull request targeting `main`.
- Explain what changed, why it helps, and how you tested it. Include screenshots for interface changes.
- Keep passwords, signing keys, API secrets, customer records and M-Pesa messages out of commits and issues. Use sample data.

## Source layout

The ZIP files are preserved project snapshots. Extract the relevant source archive to inspect its build instructions. For VYBEPASS, `vybepass-hosted-source.zip` is the newer hosted version; `vybepass-source.zip` is the earlier fresh-start version.

If proposing the first extracted source tree, put it in a clearly named directory and preserve the existing snapshots. Avoid replacing binary ZIP files for small code changes; submit readable source changes so they can be reviewed.

## Review

A pull request is a proposal, not automatic write access. Maintainer approval is required before a contribution is merged. Be respectful and discuss technical disagreements constructively. Do not submit code or assets you do not have permission to share.
